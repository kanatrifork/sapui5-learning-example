# SAPUI5 Learning Example

Hands-on exercises from the SAP "Developing UIs with SAPUI5" learning journey, built on SAP's official training template.

## What this covers
- SAPUI5 bootstrap and modularization
- Component and manifest configuration
- Views and controllers (MVC)
- Running locally with a mock server

## Run locally
    npm install
    npm run start-mock
